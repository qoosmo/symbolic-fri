# Randomized Symbolic FRI

**Polynomial binding on smooth domains up to the Johnson bound** — monograph (LaTeX).

Symbolic FRI folds with challenges `r_i·T` and ends with a polynomial `g(T) = f(r_1T, …, r_kT)`,
certifying a committed polynomial on a whole line in one run. This text proves binding of `g(T)`
as a polynomial identity, for arbitrary smooth domains and arities, with matching attacks.

- Unique binding: error `(N−B)/|K| + d/(|K|−1) + ((1+ρ)/2)^s`, tight.
- List binding, proximity, promise binding, session uniqueness, non-equivocation up to the Johnson radius.
- Goldilocks³, L = 2^20, 128 bits: s = 309 / 189 / 155 / 141 for ρ = 1/2, 1/4, 1/8, 1/16.
